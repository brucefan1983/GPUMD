# Potential files

This directory contains potential files and interface examples for GPUMD.
See the [potential documentation](../doc/potentials/index.rst) for formats and usage.

| Directory | Contents |
| --- | --- |
| [lj](lj/) | Lennard-Jones potentials for Ar. |
| [eam](eam/readme.md) | Embedded-atom-method potentials and parameter tables. |
| [adp](adp/) | Angular-dependent potentials. |
| [tersoff](tersoff/readme.md) | Tersoff potentials and references. |
| [nep](nep/readme.md) | NEP models, format documentation, and a model converter. |
| [hybrid_nep_ilp](hybrid_nep_ilp/) | NEP and interlayer potential files. |
| [hybrid_sw_ilp](hybrid_sw_ilp/) | Stillinger-Weber and interlayer potential files. |
| [hybrid_tersoff_ilp](hybrid_tersoff_ilp/) | Tersoff and interlayer potential files. |
| [DP](DP/README.md) | DeePMD-kit interface instructions. |
| [nnap](nnap/) | Cu NNAP model used in the [NNAP example](../examples/gpumd_nnap/README.md). |

Model references and parameter notes are given in the corresponding directories.
Published NEP models and datasets are available in [nep-data](https://gitlab.com/brucefan1983/nep-data).
