:attr:`compute_extrapolation`
=============================

This keyword is used to compute the extrapolation grade of structures in an NEP potential.

The extrapolation grade `gamma` can be considered as the uncertainty of a structure relative to the training set.

A structure with large `gamma` tends to have higher energy and force errors.

Similar methods have been applied to MTP ([Podryabinkin2023]_) and ACE ([Lysogorskiy2023]_). You can refer to their papers for more details.

Before computing `gamma`, you need to obtain an `active set` from your training set. Use the `nep_active scripts <https://github.com/psn417/nep_active>`_.

The `nep_maker scripts <https://github.com/psn417/nep_maker>`_ automate active learning.

Syntax
------

::

  compute_extrapolation nep_file <nep_file> asi_file <asi_file> gamma_low <gamma_low> gamma_high <gamma_high> check_interval <check_interval> dump_interval <dump_interval>

Parameters
----------

:attr:`nep_file` is the name of the NEP potential file used to compute the extrapolation grade. This model is read by this keyword and is independent of the potential used to run the MD.
It must use the :ref:`nep.txt format <nep_txt>` with ``model nep``,
``model nep_dipole``, or ``model nep_polarizability``.

:attr:`asi_file` is the name of the Active Set Inversion (ASI) file. This file is generated by the `nep_active scripts <https://github.com/psn417/nep_active>`_.

:attr:`gamma_low`: Structures whose maximum gamma is at least this value are eligible for output, subject to :attr:`dump_interval`. The default is 0.

:attr:`gamma_high`: If the maximum gamma exceeds this value, the structure is saved immediately and the simulation stops. This final write is not limited by :attr:`dump_interval`. The default is very large, effectively disabling this stopping condition.

:attr:`check_interval`: A positive integer specifying how often to calculate the gamma value. The default value is `1` (check every step).

:attr:`dump_interval`: A positive integer specifying the minimum interval between dumps. The default value is `1`.

Output
------

.. _extrapolation_dump_xyz:

Selected structures are appended to ``extrapolation_dump.xyz`` in extended XYZ format.
A structure exceeding :attr:`gamma_high` is also saved before termination.

Examples
--------

.. code::

    compute_extrapolation nep_file nep.txt asi_file active_set.asi gamma_low 5 gamma_high 10 check_interval 10 dump_interval 10

Gamma is checked every 10 steps. Structures with a maximum gamma of at least 5 are saved at least 10 steps apart.
If the maximum gamma exceeds 10, that structure is saved immediately and the simulation stops.

Notes
-----

None.
