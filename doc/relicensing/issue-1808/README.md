# GPUMD LGPL relicensing consent archive

This directory preserves the proposal and consent statements from
[Issue #1808](https://github.com/brucefan1983/GPUMD/issues/1808)
to relicense GPUMD's source code and header files under `src/`, including
subdirectories, from GPL to LGPL-3.0-or-later. Existing third-party licenses
and notices are preserved.

- Baseline: GPUMD 5.9, commit `eb7fbbf17a7886a014584aa0105f4456a514a11c`.
- Snapshot: 2026-10-05 at 12:01:58 UTC.
- All 39 listed contributors provided consent.

## Files

- [issue.md](issue.md): proposal and contributor table as captured.
- [consents.md](consents.md): consent statements with account identifiers,
  timestamps, and links to the original replies.
