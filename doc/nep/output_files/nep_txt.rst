``nep.txt``
===========

This file contains the parameters of the :term:`NEP` model generated by the training.
It can be used by the ``gpumd`` executable to run :term:`MD` simulations.

When this file is present in the directory of a new training run, its header is compared against :ref:`nep.in <nep_in>`; see :ref:`that page <nep_in>` for what happens on a mismatch.
