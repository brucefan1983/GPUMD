``nep.txt``
===========

This file contains the parameters of the :term:`NEP` model generated by the training.
Energy models can be used by the ``gpumd`` executable to run :term:`MD` simulations.

NEP model files use ``format_version 1``. A model header has the form::

  nep <num_types> <elements...>
  format_version 1
  model <model_name>

The ``model`` field identifies the model family, such as ``nep``, ``qnep2``,
or ``nep_dipole``. See the `NEP model format specification
<https://github.com/brucefan1983/GPUMD/blob/master/potentials/nep/nep_model_format.md>`_
for the complete file syntax.

Spin models are identified by ``model nep_spin`` and ``spin_version 1``.
