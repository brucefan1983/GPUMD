# Spin independent oracle fixtures

Generated by `tests_pytest/generate_spin_oracles.py` from the independent FP64 Torch/e3nn BFO prototype. The JSON records the source hashes and model SHA-256. It does not import native C++ coefficient tables or kernels. Parameters/scalers are rounded to FP32 before evaluating the FP64 reference, matching model loading.

Cases cover a large orthogonal cell, periodic triclinic multiple-image neighbors, zero spins and isolated centers; inactive Bi/O input spins are deliberately nonzero. Models cover C3/L2/S2 (64 dimensions, 7270 parameters), C2/L4/S4 and C1/L0/S1. Forces, magnetic forces and total virials come from autograd of positions, spins and homogeneous strain.

Run native checks with `python3 tests_pytest/validate_spin_model.py --workdir /path/to/new/results` after building `src/gpumd` and `src/nep`. Override `GPUMD_COMMAND`/`NEP_COMMAND` to select binaries. Runtime checks need only the Python standard library, CUDA and these frozen fixtures.

`c3l2s2_fege.nep` is a two-element runtime-driver fixture selected from the Fe/Bi ANN and type-pair coefficients of `c3l2s2.nep`, with the second element named Ge. It is not a separate numerical oracle. `model_large_box.xyz` supplies its four-atom geometry.
